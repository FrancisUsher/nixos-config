# nixos-config

Personal NixOS + home-manager configuration.

## Conventions

### App config files

- **Declarative** (most modules, e.g. `git.nix`): content generated by Nix,
  written read-only into `/nix/store`. Use for settings you set once and
  change by editing Nix.

- **`mkOutOfStoreSymlink`** (e.g. `claude-code.nix`): symlinks to a plain
  file inside this repo instead, so the app can keep writing to it live.
  Use when the tool rewrites its own config at runtime and you still want a
  baseline checked in. Runtime changes show up as a git diff.

Skip hand-rolled `home.activation` merges unless neither pattern fits.
