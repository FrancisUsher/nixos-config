# re-bootstrapping zsh

The first time I setup `zsh` I went through the setup wizard and made
all the nice configurations I liked, and then promptly deleted the
configuration file it generated thinking it was a temp/backup file.
This annoyed me a lot so the next time I went through it I didn't spend
nearly as much time or put enough thought into how I wanted it to work.
So what I ended up with is a half-assed and partially opinionated config
for zsh.

This item would then be basically going back through the bootstrapping
process and injecting my opinions. At least then I could see what it comes
up with and maybe augment it with my more advanced preferences.
